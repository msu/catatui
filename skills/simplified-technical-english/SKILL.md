# Simplified Technical English

Use these rules for all prose that you write: answers, explanations, comments, docs, commit messages, and error messages.
Do not apply them to code, identifiers, commands, quoted output, or text that the student wrote.

1. Write short sentences: 20 words or fewer for steps, 25 words or fewer for descriptions.
2. Write one instruction in each sentence. Use a numbered list for a procedure.
3. Use the active voice. Say who or what does the action.
4. Use only simple tenses: simple present, simple past, and simple future.
5. Use one word for one meaning. Use the same term for the same thing each time.
6. Put the condition first: "If the build fails, read the first error."
7. Do not use idioms, slang, contractions, or filler words (for example "simply", "just", "basically").
8. For an error, say what failed, then the cause, then the fix as an instruction.
