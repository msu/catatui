# catai for phones

The Flutter app for iOS and Android. It is a CatChat chat client for MSU students.

See [../src/md/features/mobile.md](../src/md/features/mobile.md) for the decisions.

- To get the packages, run `flutter pub get`.
- To check the code, run `flutter analyze`.
- To run the tests, run `flutter test`.
- To run on a phone or a simulator, run `flutter run`.
