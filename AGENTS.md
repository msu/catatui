# catatui

catatui is a terminal coding agent for MSU students. It is an extension to the pi coding agent, and it uses the MSU CatChat models.

See src/md/README.md for more information.

## Fixes and the rewrite

catatui is the live product until the switch to tau-harness and cat-chat-harness. After each fix commit in catatui, add a line to "Fixes to port" in ../cat-chat-harness/PLAN.md.
